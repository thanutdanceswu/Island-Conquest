# 🏝️ Island Conquest – ศึกชิงเกาะ (ออนไลน์ บน Vercel)

เล่นได้จากที่ไหนก็ได้ผ่านลิงก์เดียว ไม่ต้องอยู่ Wi-Fi เดียวกัน
คนหนึ่งสร้างห้อง ได้ **รหัสห้อง 4 ตัวอักษร** + ลิงก์เชิญ ส่งให้เพื่อนใน LINE แล้วเข้าเล่นได้เลย (2–4 คน ต่อห้อง หลายห้องพร้อมกันได้)

## วิธีทำงาน (สั้นๆ)
Vercel รันโค้ดแบบ serverless จำสถานะข้ามคำขอไม่ได้ จึงเก็บเกมของแต่ละห้องใน **Upstash Redis** (ฟรี)
และให้มือถือถามสถานะทุก ~1 วินาที (0.7 วินาทีตอนรอคนอื่นเล่น) เอนจินกติกาเป็นตัวเดียวกับเวอร์ชันเล่นในบ้าน เซิร์ฟเวอร์เป็นคนทอยเต๋า/สับไพ่/ตัดสินทุกอย่าง

## ขั้นตอน Deploy (ทำครั้งเดียว ~10 นาที)

### 1) เตรียมโค้ด
แตกไฟล์ zip แล้วอัปโหลดโฟลเดอร์นี้ขึ้น **GitHub** (repository ใหม่) — เว็บ github.com → New repository → Upload files (ลากทั้งโฟลเดอร์ รวม `api`, `lib`, `public`, `game.js`, `package.json`, `vercel.json`)

### 2) สร้างฐานข้อมูล Upstash (ฟรี)
1. สมัคร/ล็อกอิน <https://vercel.com> ด้วย GitHub
2. ที่แดชบอร์ด Vercel เมนู **Storage** (หรือ Marketplace) → เลือก **Upstash → Redis** → Create (เลือกภูมิภาคใกล้ไทย เช่น Singapore, แพ็กเกจ Free)
3. หลังสร้าง ให้ **Connect to Project** กับโปรเจกต์ในข้อ 3 ระบบจะเติมตัวแปร `KV_REST_API_URL` และ `KV_REST_API_TOKEN` (หรือ `UPSTASH_REDIS_REST_URL/TOKEN`) ให้เอง โปรแกรมรองรับทั้งสองชื่อ

> ถ้าสร้างฐานข้อมูลที่เว็บ upstash.com เอง: คัดลอก REST URL และ REST TOKEN ไปใส่เป็น Environment Variables ชื่อ `UPSTASH_REDIS_REST_URL` และ `UPSTASH_REDIS_REST_TOKEN` ในโปรเจกต์ Vercel (Settings → Environment Variables)

### 3) Deploy
1. Vercel → **Add New → Project** → เลือก repository ในข้อ 1 → **Deploy** (ไม่ต้องตั้งค่าอะไรเพิ่ม ไฟล์ `vercel.json` กำหนดให้แล้ว)
2. ถ้าเชื่อมฐานข้อมูลหลัง deploy แล้ว ต้อง **Redeploy** หนึ่งครั้งเพื่อให้ตัวแปรมีผล
3. ได้ลิงก์ เช่น `https://ชื่อโปรเจกต์.vercel.app` เปิดแล้วกด “สร้างห้องใหม่”

### ตรวจว่าตั้งค่าถูกไหม
สร้างห้องแล้วขึ้นรหัสห้อง = ใช้ได้ ถ้าขึ้น “เซิร์ฟเวอร์ผิดพลาด: Redis …” แปลว่า URL/TOKEN ผิดหรือยังไม่ได้ Redeploy

## วิธีเล่น
1. คนแรกกด **สร้างห้องใหม่** → ใส่ชื่อ → กด **คัดลอกลิงก์เชิญ** ส่งให้เพื่อน (หรือบอกรหัสห้อง)
2. เพื่อนเปิดลิงก์ ใส่ชื่อ เลือกตัวละคร คนสร้างห้อง (เจ้าของห้อง) กดเริ่มเกม
3. กติกาเหมือนเวอร์ชันเล่นในบ้านทุกอย่าง ดูในปุ่ม 📖 (สรุปกติกาและไพ่ทั้ง 9 แบบ)
4. มีคนหลุด/ค้าง: เจ้าของห้องกด 📖 → “ข้ามเทิร์น” หรือ “ข้ามการตอบโต้”
5. รีเฟรชหน้าได้ กลับเข้าที่นั่งเดิมอัตโนมัติ (เปลี่ยนเครื่อง: เปิดลิงก์เดิมแล้วใส่ชื่อเดิม ใช้ได้เมื่อที่นั่งนั้นออฟไลน์เกิน ~25 วินาที)
6. ห้องหมดอายุเองหลังไม่มีการเล่น 24 ชั่วโมง

## ข้อจำกัดที่ควรรู้
- **โควตาฟรี:** แต่ละคนที่เปิดเกมค้างไว้ใช้ Redis ราว 1–1.5 คำสั่งต่อวินาที 4 คนเล่นต่อเนื่องประมาณ 25+ ชั่วโมงต่อเดือนตามโควตาฟรีของ Upstash (เช็กโควตาปัจจุบันที่หน้าแพ็กเกจของ Upstash) หน้าจอที่ถูกซ่อนจะลดความถี่ลงเอง
- **หน่วง ~1 วินาที:** เมื่อเพื่อนเดิน เครื่องคุณเห็นผลภายใน ~1 วินาที (ตอนคุณเป็นคนกดเอง เห็นทันที)
- **ไม่มีล็อกอิน:** ใครรู้รหัสห้องก็เข้าได้ (จนกว่าห้องเต็มหรือเกมเริ่ม) อย่าแชร์รหัสในที่สาธารณะ และไม่ควรใช้ชื่อจริง
- ผู้เล่นใหม่เข้ากลางเกมไม่ได้ (ผู้เล่นเดิมกลับเข้าด้วยชื่อเดิมได้)

## ทดลองบนเครื่องตัวเอง (ไม่ต้องมี Redis)
```
node dev.js        # เปิด http://localhost:3000  (เก็บเกมในหน่วยความจำ เหมาะสำหรับดูเฉยๆ)
node test-online.js   # ทดสอบ API (ใช้ Upstash จำลอง)
node test-e2e.js      # ทดสอบเล่นจริงในเบราว์เซอร์ (ต้องมี playwright)
```
กติกาที่ตั้งค่าเริ่มต้นไว้และยังไม่ได้ยืนยัน แก้ได้ที่ `game.js` (RULES) และ `public/board.js` (CONFIG)

## ไฟล์
```
api/        ฟังก์ชัน Vercel: create, join, state, action
lib/        store.js (Upstash REST / หน่วยความจำ), rooms.js (ล็อก/โหลด/เซฟห้อง), http.js
game.js     เอนจินกติกาเกม
public/     หน้าเว็บ ภาพการ์ด บอร์ด ตัวเล่น
vercel.json package.json dev.js test-*.js
```

## เสียง
- `public/audio/waves.mp3` เสียงคลื่นทะเล (วนต่อเนื่อง) และ `public/audio/bgm.mp3` เพลงพื้นหลัง เริ่มเล่นหลังแตะหน้าจอครั้งแรก (ข้อจำกัดของมือถือ)
- ปุ่ม 🔊/🔇 ที่แถบบน (หรือมุมขวาบนก่อนเข้าเกม) เปิดปิดได้ จำค่าไว้ในเครื่องแต่ละคน
- เสียงเอฟเฟกต์ (ทอยเต๋า เดิน เตะ โล่ สะท้อน สลับ ขโมย ถึงเทิร์น มีคนให้ตอบโต้ เกมจบ) สร้างในเบราว์เซอร์ ไม่ใช้ไฟล์
- ปรับความดัง/เปลี่ยนเพลงที่ `public/audio.js` (ตัวแปร TRACKS) หรือแทนที่ไฟล์ mp3 ชื่อเดิม
- **ลิขสิทธิ์:** เพลง `bgm.mp3` ตัดมาจากเพลงของเกมโปเกมอน ซึ่งมีลิขสิทธิ์ ถ้าเปิดเว็บเป็นสาธารณะ อาจถูกแจ้งลบได้ ควรเปลี่ยนเป็นเพลงที่ใช้ได้ฟรี (เช่น Pixabay Music) ถ้าจะเผยแพร่วงกว้าง
